# Self-host package

- `LOCAL-DEV.md` - exact steps to run everything on your laptop (start here)
- `deploy/` - docker-compose, Caddyfile, .env templates, SQL, scripts, hosting-team runbook
- `code-templates/` - Better Auth, PostgREST client, MinIO upload code to copy into the app
- `Dockerfile`, `.dockerignore`, `next.config.snippet.js` - repo root files

Untested against a live Docker environment: run through LOCAL-DEV.md first and fix anything it surfaces.
